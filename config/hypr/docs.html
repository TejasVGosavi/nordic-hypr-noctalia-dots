WS 4 Complete Dotfiles Tree, Scripts & System Configs
Hyprland 0.56.2 Lua + Noctalia v5 TOML + GTK3/Greeter

1. Core Hyprland Lua Files ~/.config/hypr/*.lua

hyprland.lua sets up your 1080p@60Hz monitor, input, touchpad (`tap_to_click`), and 3-finger swipe, then loads:
• theme.lua: 2px 45° Frost borders (`general.col`), 2-pass blur, and the `global` animation tree (`popin 80%`).
• exec.lua: Wayland env vars, DBus sync, `noctalia`, and `cliphist`.
• rules.lua: `no_anim = true` blur mask on Noctalia layers, persistent workspaces bound to `HDMI-A-1`, and floating dialogs.
• keybind.lua: All compositor, media, and plugin shortcuts.

2. Modular Lua Extensions & Idle ~/.config/hypr/

• monitors.lua / inputs.lua / startup.lua / windowrules.lua: Modular extensions matching your classic layout without duplicate gesture warnings.
• animations/default.lua & minimal.lua: Switchable Caelestia fluid and low-latency Radeon R3 presets.
• hypridle.conf: Dims at 5 min, locks via `noctalia msg lock` at 10 min, and powers off display (DPMS) at 15 min.

3. Custom Helper Scripts ~/.config/hypr/Scripts/

• gamemode.sh: Instant Radeon R3 performance booster—toggles off blur, shadows, gaps, and animations for gaming, and restores Nordic glass on second run.
• browser-launcher.sh: Automatically detects and launches your preferred Wayland browser (`firefox`, `brave`, `zen-browser`).

4. Noctalia Config & Login Greeter config.toml & greeter.toml

• ~/.config/noctalia/config.toml: Unified TOML config defining the floating top bar, `cpu`/`gpu`/`ram`/`disk` gauges, bottom dock, 5 balanced desktop widgets, and plugin settings.
• /var/lib/noctalia-greeter/greeter.toml: Themes the pre-session `greetd` login screen with your `#88C0D0` / `#2E3440` Nord palette and `Nordzy-dark` cursor.

5. Thunar GTK3 & Terminal Rice gtk-3.0, kitty & nvim

• ~/.config/gtk-3.0/gtk.css & settings.ini: Fixes Thunar's dark-mode contrast with `#D8DEE9` Snow Storm text and a `#3B4252` path bar.
• ~/.config/kitty/kitty.conf: `14px` padding + `0.86` opacity.
• ~/.config/nvim/init.lua: Transparent Nordic highlight engine.
• ~/.config/starship.toml: Nordic pill prompt with `scan_timeout = 100`.

6. Desktop & Lockscreen Widgets [desktop_widgets]

Calibrated for `1920x1080` (`HDMI-A-1`) with the alignment grid hidden (`visible = false`):
• Centre: Hero Clock (`960, 220`) + Fancy Visualizer (`960, 390`)
• Left: Monthly Calendar Card (`220, 230`)
• Right: Weather Card (`1700, 190`) + Media Player (`1700, 390`)

WS 5 How to Edit Configs & Troubleshoot Common Tasks
Direct Config-File Workflows

A. Editing Noctalia TOML Without GUI Overrides config.toml

Noctalia keeps `~/.local/state/noctalia/settings.toml` in memory while running and overrides `~/.config/noctalia/config.toml`. Whenever you edit `~/.config/noctalia/config.toml` directly, apply it cleanly with: 

killall noctalia
cp ~/.config/noctalia/config.toml ~/.local/state/noctalia/settings.toml
noctalia config validate ~/.config/noctalia
noctalia & disown

B. Re-enabling Bongo Cat Keyboard Detection /dev/input

If Bongo Cat stops slapping keys after a kernel update or unplugging your USB keyboard, refresh the ACL read permissions on `/dev/input/event*` without rebooting: 

# Grant immediate read access to evtest for Bongo Cat
sudo setfacl -m u:$USER:r /dev/input/event*

C. Customizing Top Bar Resource Monitors config.toml

Your centre bar pill groups `["cpu", "gpu", "ram", "disk"]`. You can switch `visualization` between `"gauge"`, `"sparkline"`, or `"none"`, or change `"ram_pct"` to `"ram_used"` (GiB): 

[widget.ram]
stat = "ram_pct"          # Or "ram_used" for GiB
visualization = "gauge"   # "gauge" | "sparkline" | "none"
show_value = true
type = "sysmon"

D. Installing the Noctalia Login Greeter Theme greeter.toml

To copy your themed `greeter.toml` to the system `greetd` directory and set the required `greetd:greetd` ownership: 

sudo install -Dm644 greeter.toml /var/lib/noctalia-greeter/greeter.toml
sudo chown -R greetd:greetd /var/lib/noctalia-greeter
